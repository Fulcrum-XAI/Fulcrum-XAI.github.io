# MSEF project website

Public project page for *Tracing the Evolution of Oracle Bone Characters Across Three Millennia*.

The site contains the paper PDF, interactive figures, data examples, and source-corpus metadata. The data repository is <https://github.com/Fulcrum-XAI/MSEF-data>. Model source code is not published here.
